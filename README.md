# Lakhan Cycle Service Centre - Official Website

Yeh website **Lakhan Cycle Service Centre** (House No. 244, near Govt. School, Keshavpura, Santoshi Nagar, Kota, Rajasthan) ke liye banayi gayi hai.

## Features Included:
- **Direct Calling & WhatsApp**: Owner ke number `+91-9694987032` everywhere integrated hai.
- **Interactive Bill Estimator**: Customer puncture, tubes, full service tick karke total check kar sakte hain aur direct WhatsApp par send kar sakte hain.
- **Tyre & Tube Guide**: Har size (Kids, MTB, 28-inch standard, 29er) ki detail shamil hai.
- **Google Maps Integration**: Kota Keshavpura location embed hai aur 1-click direction button hai.
- **Mobile Responsive**: Mobile screen ke liye floating sticky call/whatsapp buttons available hain.
